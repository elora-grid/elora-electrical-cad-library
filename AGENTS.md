# Working with this repository

- The public feed at https://eloragrid.ai/tools/cad-library/catalogue.json?all=1 is the source of truth.
- `data/`, `schema/`, `equipment/`, `openapi.json` and `README.md` are generated by `npm run sync`.
- Report source corrections through issues; update the website catalogue before regenerating snapshots.
- After changing scripts, run `npm test`, `npm run sync`, and `npm run validate`.
- Never export private local paths, storage credentials, temporary signed URLs, customer drawings or request contacts.
- Retain exact original checksums, separate delivery checksums, manufacturer attribution and rights evidence.
- Never convert `unknown` rights into an asserted licence or infer certification from discovery regions.
- Code/tests are MIT. Elora-authored catalogue metadata/docs are CC BY 4.0. Manufacturer files retain per-file rights.
