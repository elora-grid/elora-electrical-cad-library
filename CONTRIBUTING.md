# Contributing

Help expand the collection by reporting missing official sources, broken links, updated revisions, format errors or rights corrections.

Include the manufacturer, exact model/part number where available, official source URL, format, relevant discovery markets and supporting evidence. Official manufacturer-endorsed portals are acceptable when the endorsement is documented. Identify whether the source is an exact product, family archive, general library or configurator.

Use the repository issue forms. Do not upload customer drawings, project files, account credentials or personal contact details. For a personal drawing request, use Request CAD on the [equipment page](https://eloragrid.ai/tools/cad-library).

The live Elora catalogue is authoritative. Data and equipment pages in this repository are generated; corrections need to be applied to the website feed before regeneration. Pull requests are welcome for exporter, documentation and validation improvements. A suggested source in an issue is not treated as verified until its official provenance is checked.

Run `npm test` and `npm run validate` for code changes. Run `npm run sync` to refresh the public snapshot. Node.js 22 or newer is required; there are no external package dependencies.

By contributing original catalogue metadata/documentation, you agree to CC BY 4.0. Original scripts/tests are contributed under MIT. You must have the rights to contribute your material; this does not relicense third-party CAD or manufacturer content.
